# Coulibaly Zakaria Portfolio

Portfolio professionnel personnel construit avec React, Vite, Tailwind CSS, Framer Motion et Lucide React.

## Stack

- React
- Vite
- JavaScript
- Tailwind CSS
- Framer Motion
- Lucide React

## Installation

```bash
npm install
```

## Lancement local

```bash
npm run dev
```

## Build de production

```bash
npm run build
```

## Structure principale

```bash
src/
  components/
  data/
  App.jsx
  main.jsx
  index.css
public/
  cv/
  favicon.svg
  images/
```

## Modifier les projets

Les projets sont centralisés dans :

```bash
src/data/projects.js
```

## Ajouter des images

Les visuels sont stockés dans :

```bash
public/images/
```

## Ajouter un CV

Le fichier PDF est disponible dans :

```bash
public/cv/cv-zakaria-coulibaly.pdf
```

## Déploiement

Le site est prêt pour Vercel ou Netlify.

### Vercel

1. Connecter le dépôt GitHub.
2. Choisir le projet.
3. Déployer.

### Netlify

1. Importer le dépôt GitHub.
2. Configuration du build : `npm run build`
3. Dossier de publication : `dist`
